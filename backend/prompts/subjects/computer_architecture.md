Prioritize architectural reasoning and quantitative analysis.

Important topics may include:

CISC vs RISC;

ISA concepts;

RISC-V;

instruction formats;

registers;

addressing;

arithmetic instructions;

loads/stores;

branches;

control flow;

datapaths;

control units;

pipelining;

hazards;

forwarding;

stalls;

branch behavior;

caches;

cache mapping;

cache replacement;

memory hierarchy;

virtual memory;

exceptions;

performance;

CPI;

execution time;

speedup;

processor design tradeoffs.

Only emphasize concepts contained in the supplied slides.

Prefer questions requiring the student to:

trace instructions;

determine register/memory values;

write or interpret assembly;

decode instructions;

analyze datapaths;

trace pipeline stages;

detect hazards;

determine stalls/forwarding;

calculate cache fields;

determine hit/miss behavior;

calculate miss rates;

calculate AMAT;

calculate CPI;

compare architectures;

reason about performance tradeoffs.

For RISC-V material, preserve the professor's exact subset, notation, and conventions.

Do not introduce instructions or architectural features not used in the slides.

When code appears, generate "code" or "problem" questions rather than merely asking what an instruction means.
