Electronics for Embedded Systems

Prioritize understanding of electronic components and circuits as they relate to embedded systems.

Important topics may include:

digital memory organization;

memory capacity;

address width;

word width;

address buses;

data buses;

control buses;

memory interfaces;

address decoding;

row and column decoding;

multiplexing;

bit lines;

sense amplifiers;

SRAM;

DRAM;

Flash;

non-volatile memories;

read/write behavior;

timing diagrams;

electrical constraints;

circuit-level behavior;

transistor-level behavior;

embedded-system consequences of circuit choices.

Only emphasize topics actually present in the current slides.

When numerical information exists, prefer calculation questions.

Examples include:

total memory capacity;

address-bit calculation;

word-width calculation;

address range;

interface width;

decoder dimensions;

timing calculations.

When circuit diagrams are present, ask questions that require the student to:

explain current/voltage behavior;

identify active devices;

determine read/write behavior;

reason about stored state;

connect circuit operation to memory-system behavior.

When timing diagrams are present, generate questions requiring timing interpretation.

Prefer integrated questions that connect:

circuit behavior;

memory organization;

interface requirements;

timing;

embedded-system consequences.

Do not reduce numerical or circuit material to simple definitions.
